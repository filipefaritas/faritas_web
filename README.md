# Faritas v1

## Publicar no GitHub e Vercel

1. GitHub > Create repository.
2. Nome: `faritas-web`.
3. Criar o repositório.
4. Fazer upload de todos os ficheiros deste ZIP para a raiz.
5. Vercel > Continue with GitHub.
6. Importar `faritas-web`.
7. Framework: Other.
8. Clicar em Deploy.

## Ligar faritas.co

Vercel > Project > Settings > Domains > adicionar `faritas.co`.
Depois copie para o DNS do seu registrador exatamente os registos indicados pela Vercel.

## Nota

O formulário guarda contactos apenas no navegador. A próxima versão deverá ser ligada a uma base de dados ou serviço de formulários.
